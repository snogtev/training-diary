*   **Важно:** Требуется Python 3.8+

## 🎯 Функционал


| Возможность | Описание |
| :--- | :--- |
| ➕ **Тренировки** | Создание тренировки с любым набором упражнений |
| ✏️ **Редактирование** | Изменение веса, подходов и повторений |
| 🗑️ **Удаление** | Быстрое удаление лишних упражнений |
| 📅 **История** | Просмотр всех сохранённых записей по датам |
| ✅ **Валидация** | Контроль ввода (вес 0-1000 кг, подходы 1-50) |
| 💾 **База данных** | Автоматическое сохранение в SQLite |
